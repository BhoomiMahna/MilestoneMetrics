# Week 2: Authentication & Questionnaire UI

## Building the Login and Basic Questionnaire Pages

**Task:**
Develop the initial frontend for the Authentication page (Login/Signup) and the basic Financial Questionnaire page.

**Relevant Context:**
The app needed a way for users to log in and a form to capture their financial data. Both pages needed to be responsive and match the design system established in Week 1.

**Key Observation:**
Building a two-column, responsive layout with a tabbed authentication form requires careful state management. We needed a way to toggle between the login and signup forms without refreshing the page. The questionnaire also needed to capture multiple fields (income, spending, investments, age, goal amount, timeline).

**Solution:**
1. **Authentication UI:** Implemented a tab-based toggle using React's `useState` hook (`activeTab`) to switch between Login and Signup. Designed the layout using CSS Grid (`md:grid-cols-2`) for a responsive split-screen view. Built the visual "card" elements on the left side to give the app personality.
2. **Basic Questionnaire UI:** Created reusable components (`Field` and `Chip`) to maintain consistency across all inputs. Implemented a single `data` state object using `useState` to hold all form fields, with a generic `set()` function to update specific keys dynamically.
