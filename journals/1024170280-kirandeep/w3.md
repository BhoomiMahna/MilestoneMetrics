# Week 3: Questionnaire Finalization & Page Integration

## UI Polish, Client-Side Routing, and Visual Anchoring

**Task:**
Finalize the Questionnaire UI, implement seamless client-side routing from the Authentication page, and refine the overall layout spacing and visual assets.

**Relevant Context:**
Initially, the application had two separate components (`Auth.jsx` and `Questionnaire.jsx`), and `App.jsx` manually swapped between them by commenting out code (`//return <Auth />`). This is not scalable. Additionally, the Questionnaire page is a long, scrolling form. Without a persistent visual element, the right side of the screen felt empty and unbalanced as the user scrolled down. The original background image also lacked thematic relevance to the financial goal-setting purpose of the app.

**Key Observation:**
1. We needed a smooth, client-side transition between the two pages without a full page reload.
2. We needed a way to keep the user visually engaged on the right side of the screen while they filled out the long form on the left.
3. The spacing between the form, the visual elements, and the screen borders needed to be balanced to look professional.

**Solution:**
1. **State Lifting & Client-Side Routing:** Lifted the authentication state to `App.jsx` using `useState` (`loggedIn`). Passed an `onLogin()` callback down to `Auth.jsx`. When the user submits the login form, `onLogin()` is triggered, setting `loggedIn` to `true`, which seamlessly unmounts the `Auth` component and mounts the `Questionnaire` component without a page refresh.
2. **Visual Asset Redesign:** Replaced the original, generic background image with a custom "Goal Jar" illustration. This redesign was done to strongly reinforce the application's core theme of financial goal-setting and savings.
3. **Persistent Visual Anchoring (Sticky Positioning):** Applied `sticky top-24` to the Goal Jar container. This ensures the illustration remains a persistent visual anchor alongside the form as the user scrolls, eliminating empty screen space and improving the overall UX.
4. **Layout & Spacing Optimization:** Refined the CSS Grid configuration (`lg:grid-cols-[1fr_auto]`) and adjusted the outer padding and grid gap (`px-12`, `gap-12`). This established perfectly symmetrical spacing between the form, the visual asset, and the right edge of the screen for visual harmony.
5. **Dynamic Calculation Logic:** Integrated frontend calculation logic (`Goal Amount / (Timeline in Years * 12)`) to provide immediate, dynamic feedback to the user (displaying the required "Monthly Savings Target") before the data is sent to the backend for validation.
