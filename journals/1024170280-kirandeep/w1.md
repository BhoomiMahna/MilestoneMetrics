# Week 1: Project Planning & Initial UI Design

## Gantt Chart and Visual Direction

**Task:**
Create the project Gantt chart and establish the initial UI design and wireframes.

**Relevant Context:**
The team needed a visual timeline to track our weekly progress. Additionally, we needed to agree on the visual direction of the application so that all frontend screens would look consistent. 

**Key Observation:**
Breaking down the project into phases helps prevent scope creep. Establishing a color palette and typography early prevents having to rewrite CSS later.

**Solution:**
1. **Gantt Chart:** Designed the Gantt chart to map out the weekly phases of the project. Coordinated the phase breakdown with the team's use case diagram to ensure the timeline aligned with identified system functionalities.
2. **Initial UI Design:** Created the initial UI mockups and established the design system (color palette: beige `#F4EBDD`, dark `#171513`, accent orange `#E8893A`, and typography) to be used consistently across all frontend screens.
