# W1 : Questionnaire Backend

**My Contribution: Questionnaire Backend**

Developed the backend for the financial questionnaire using Spring Boot. Implemented the questionnaire entity, DTOs, repository, service, and REST controller. Added input validation, duplicate questionnaire prevention, and create, retrieve, and update operations. Implemented the logic for calculating the required monthly savings based on the user's goal amount and timeline. Integrated the questionnaire module with Supabase PostgreSQL and tested the API flow for validation, data persistence, retrieval, and updates.
